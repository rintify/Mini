# メイドインワリオみたいなゲーム(仮)
ひとりひとりでメイドインワリオみたいなゲームを作りましょう

## 作るもの
メイドインワリオ風  
ゲームの雰囲気もメイドインワリオによせる
## 開発方法
+ 一人一人5s~10sでできる2Dミニゲーム考えて作る
+ Githubで共有してるプロジェクトのAssetフォルダ下にミニゲームごとにフォルダを作成
+ 基本的にそのフォルダ内にシーンやスクリプトを入れて開発を進める
  
> [!NOTE]
> こまめにpush pullする事  
> Unityをいじって閉じるときは必ずpushする

## Unity
バージョン 2022.3.7f1
## 画面比
16:9
## 全体のシステム・UI
ゲーム全体を通した失敗数のカウントは後で実装する
共通のUIのコーディングはソウポンに任せるかも
## 音響
メニューのBGMはさっそく太田さんに作ってもらう 
太田さんがメイドインワリオを参考にBGMを量産して、それをあとから各ゲームに当てはめる  
足りなかったら他のフリーBGMで代用
ファイル形式 wav
