# メイドインワリオみたいなゲーム(仮)
ひとりひとりでメイドインワリオみたいなゲームを作りましょう

## 作るもの
メイドインワリオ風
## 開発方法
+ 一人一人5s~10sでできる2Dミニゲーム考えて作る
+ Githubで共有してるプロジェクトのAssetフォルダ下にミニゲームごとにフォルダを作成
+ 基本的にそのフォルダ内にシーンやスクリプトを入れて開発を進める
  
> [!NOTE]
> こまめにpush pullする事  
> Unityをいじって閉じるときは必ずpushする
